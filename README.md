## 核心特性

### 1. 轻量采集端

- **非阻塞采集**: `psutil.cpu_percent(interval=None)`
- **自适应频率**: CPU < 50% → 60秒, CPU > 80% → 5秒
- **端口探测**: 比 `process_iter()` 快 100 倍

### 2. 推送引擎

- **批量发送**: 累积 10 条或 5 秒窗口
- **失败重试**: 指数退避，最多 5 次
- **断网容灾**: 本地缓存最多 1000 条

### 3. 云端 API

- **异步高性能**: FastAPI + asyncpg
- **时序数据库**: PostgreSQL + TimescaleDB
- **实时推送**: WebSocket

### 4. 现代前端

- **React + Tremor**: 专为 Dashboard 设计
- **Tailwind CSS**: 现代化样式
- **响应式**: 完美支持移动端
